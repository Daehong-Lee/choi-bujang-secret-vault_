재현 안내

  1. npm install
  2. npm run decider:test — 가상 판정 연습
  3. npm run detect:test — 가상 탐지 사건 연습
  4. 자료실 로그인 → 등록 기기 승인 → 기존 메모 ID 조회로 실제 정상 흐름을 확인합니다.
  5. npm run bundle — 실제로 실행된 자기 점검만 제출 묶음에 기록합니다.

학생 작업: src/decider.mjs, src/detect.mjs, 접속 앱과 자료실. 제공 엔진/계약: ALEPH SDP 엔진의 계약 및 실행기이며, 로컬 연습 결과는 심판 판정이 아닙니다.
